Documentação do Projeto

Este espaço reúne as principais referências da aplicação desenvolvida para cumprir os requisitos do documento Projeto Prático – Programação para Web – 2025. Utilize os atalhos abaixo para navegar entre funcionalidades, revisar decisões de arquitetura e consultar o plano de adequação.

Requisitos Funcionais

Visão resumida de como cada requisito foi implementado e onde localizá-lo no código.

  • RF-01: Autenticação por formulário em /login usando Elytron JDBC. Concluído
  • RF-02: CRUD de usuários em /users (perfil ADMIN). Concluído
  • RF-03: Gestão de perfis em /profiles com validações de uso. Concluído
  • RF-04: Navegação consistente via menu global e breadcrumbs reutilizáveis. Concluído
  • RF-05: Casos de domínio — notas em /notes e tarefas em /tasks (perfis USER e ADMIN), com validações de propriedade, status e prazos. Concluído
  • RF-06: Auditoria com rastreabilidade em /audit (filtros por usuário, método, recurso, entidade e data). Concluído*

Arquitetura

A aplicação segue o padrão MVC com camadas separadas e comunicação via DTOs.

  • Controllers: src/main/java/com/robsonbs/controller
  • Serviços (BO): src/main/java/com/robsonbs/service
  • DAOs Panache: src/main/java/com/robsonbs/dao
  • Entidades JPA: src/main/java/com/robsonbs/model
  • Templates Qute: src/main/resources/templates
  • Plano de adequação: docs/plano-adequacao.md
